Lucky — Semi-Autonomous AI Agent Ecosystem

Modular multi-engine AI assistant architecture in Python and Streamlit featuring dual local/cloud LLM fallback, file-based configuration, and specialized autonomous sub-agents.

Executive Summary & Motivation

Decoupling agent intelligence from cloud dependency.

Most conventional AI chat interfaces are rigid wrappers around single proprietary API endpoints. When connectivity drops or API quotas throttle requests, the entire workflow grinds to a halt. Furthermore, user preferences and agent personas often remain trapped inside opaque database schemas.

Lucky was engineered from the ground up as a resilient, semi-autonomous assistant ecosystem. It implements a dual-engine inference pipeline: high-throughput, private local inference powered by Ollama (Llama 3.1) with automatic fallback to Gemini Cloud for complex analytical queries requiring broad world knowledge or extended reasoning.

Configuration and persona states are preserved through an auditable, file-based architecture (SOUL for agent persona and ethical bounds, IDENTITY for technical capabilities and system instructions, and USER for evolving profile preferences), paired with local JSON memory persistence.
